# Mothership 1e – Regole

Manuale di consultazione delle regole di **Mothership** (First Edition), redatto a partire dai quattro volumi del box base:

| Volume | Sezioni |
|---|---|
| Player's Survival Guide | Personaggio, Regole base, Violenza, Sopravvivenza, Port e Contractor |
| Warden's Operations Manual | Warden |
| Shipbreaker's Toolkit | Navi |
| Unconfirmed Contact Reports | Creature |

Il testo riporta esclusivamente regole, procedure, tabelle e valori. Ambientazione, testo narrativo ed esempi di gioco sono omessi.

## Convenzioni

- I termini di gioco restano in inglese (Stat, Save, Stress, Panic Check, Wound, Warden, ecc.).
- Notazione dei dadi: `1d100`, `2d10`, `1d5`, `1d20`. `[+]` = Advantage, `[-]` = Disadvantage.
- Valuta: credits (`cr`); `kcr` = migliaia, `mcr` = milioni, `bcr` = miliardi.
