# Armi delle navi

Le armi della nave aumentano la Stat Battle e consentono di infliggere Megadamage (MDMG) nel [combattimento tra navi](combattimento.md).

## Regole di installazione

- Ogni arma occupa 1 Hardpoint. Il numero di Hardpoint limita il numero di armi installabili (vedi Upgrade [Hardpoint](potenziamenti.md#major-upgrade)).
- L'installazione richiede 2 settimane in porto.
- Il costo indicato vale per navi Class-I. **Costo totale = costo indicato × Class della nave.**
- Il bonus di ogni arma installata si somma al valore Base di Battle.
- Una nave senza armi offensive non infligge MDMG; con almeno un'arma offensiva infligge l'MDMG Base del suo profilo (vedi [Tipi di nave](tipi_di_nave.md)).

|---|---|

## Rifornimento delle armi

- Dopo ogni scontro in cui sono state usate le armi della nave, è obbligatorio rifornirle.
- Senza rifornimento: i Battle Check del successivo combattimento tra navi sono a [-]; dal combattimento ancora successivo, tutti i Battle Check falliscono automaticamente.
- Il rifornimento avviene in porto. Il costo indicato vale per navi Class-I. **Costo totale = costo indicato × Class della nave.**

| Arma | Costo di rifornimento (Class-I) |
|---|---|
| Autocannon | 100kcr |
| Lasers | 50kcr |
| Light Missiles | 200kcr |
| Heavy Missiles | 300kcr |
| Particle Beam | 75kcr |
| Railgun | 400kcr |

## Fighter

Ogni Fighter trasportato conferisce +1 Battle alla nave (massimo +10). Vedi [Veicoli Class-0](veicoli_classe_0.md#fighter).
